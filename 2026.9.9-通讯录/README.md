# C 语言通讯录练习

基于动态顺序表的控制台通讯录，记录我从整数顺序表到联系人增删查改的学习过程。

## 功能

- 1：添加联系人
- 2：删除联系人
- 3：展示所有联系人
- 4：按姓名查找
- 5：修改联系人
- 0：退出并释放内存

联系人包含姓名、性别、年龄、电话和地址。容量不足时，底层顺序表动态扩容。

## 文件分工

| 文件 | 作用 |
| --- | --- |
| `test.c` | 程序入口、菜单循环、退出清理 |
| `contact.h` | 联系人类型与通讯录函数声明 |
| `contact.c` | 添加、删除、查找、修改和展示 |
| `Seqlist.h` | 顺序表类型与函数声明 |
| `Seqlist.c` | 动态内存、插入、移动、查找和修改 |

`PeoInfo` 表示一个联系人的类型，`person` 是保存一个人信息的变量；`contact` 是顺序表类型的别名，`con` 表示整本通讯录。

## 编译运行

在源码目录中使用 GCC，三个 `.c` 文件需要一起编译：

```sh
gcc -Wall -Wextra -std=c11 -g test.c contact.c Seqlist.c -o contact.exe
```

Windows PowerShell 中运行：

```powershell
.\contact.exe
```

源码使用 UTF-8。Windows 下入口设置控制台 UTF-8 输入输出代码页。

## 当前版本限制

这是学习版，不是完整的生产软件：

- 菜单和年龄暂时要求输入合法数字，文本不含空格且不超长；尚未完善输入校验。
- 按姓名查找，同名时只处理第一个联系人。
- 修改需要重新填写该联系人的全部字段，不会修改其他下标的联系人。
- 数据仅在内存中，退出后不保留，尚未实现文件保存。
- `DestroyContact` 目前只有声明，实际清理由 `main` 末尾的 `free` 和成员重置完成。
- 字符数组容量以字节计，不等于汉字个数。

保留学习时的原始写法，包括菜单变量名 `intput`，后续再逐步整理。

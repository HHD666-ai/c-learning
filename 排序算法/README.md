# C语言数据结构学习：八大排序算法详解与代码实现

把 `[5, 2, 4, 2]` 排成升序时，插入排序会把 `2` 插进已经排好的前缀，选择排序会先从整段里找最小值。同样是升序，每种算法每轮能保证的事情不同。下面对照仓库里的独立练习，看每个循环结束时究竟完成了哪一步。

## 1. 插入排序 InsertSort

源码见 [插入排序/main.c](../插入排序/main.c)。

第 `i` 轮开始时，`[0, i - 1]` 已经有序，`[i, n - 1]` 是待处理区。先把 `a[i]` 存到 `tmp`，这样右移元素时就可以覆盖 `a[i]`。`j` 从有序区的最后一格向左找。

```c
tmp=a[i];
j=i-1;
while(j>=0&&a[j]>tmp){
    a[j+1]=a[j];
    j--;
}
a[j+1]=tmp;
```

例如把 `3` 插入 `[2, 4, 5]`，先右移 `5`，再右移 `4`，在 `2` 后写入 `3`。`j` 停在插入位置的前一格，所以写的是 `a[j + 1]`。比较条件用 `>`，相等的元素会保留先后。交互演示最多读取 1000 个元素，元素值必须在 `int` 范围内。

## 2. 希尔排序 ShellSort

源码见 [希尔排序/main.c](../希尔排序/main.c)。

希尔排序把插入排序的步长从 `1` 换成 `gap`。例如 `gap = 4` 时，下标 `0、4、8` 属于同组，`1、5、9` 属于另一组。外层让 `gap` 从 `n / 2` 开始，每轮除以 2，直到做完 `gap = 1` 的全数组插入排序。

```c
while(j>=0&&a[j]>tmp){
    a[j+gap]=a[j];
    j-=gap;
}
a[j+gap]=tmp;
```

遍历待插入元素的 `i` 每次加 1，可以依次经过各组。组内找插入位置的 `j` 每次减 `gap`。跨距移动可能改变同值元素的先后，时间复杂度也取决于选用的增量序列。

## 3. 选择排序 SelectSort

源码见 [选择排序/main.c](../选择排序/main.c)。

每轮固定位置 `i`，扫描 `[i, n - 1]`，用 `minIndex` 记录目前最小值的**下标**。扫描完成后，将它与这段的首元素交换。下一轮从 `i + 1` 开始。

```c
int minIndex=i;
for(int j=i+1;j<n;j++){
    if(a[j]<a[minIndex]){
        minIndex=j;
    }
}
```

例如 `[2ₐ, 2ᵦ, 1]` 的第一轮会把 `1` 和 `2ₐ` 交换，得到 `[1, 2ᵦ, 2ₐ]`。这一次交换就改变了两个 `2` 的先后。

## 4. 堆排序 HeapSort

源码见 [堆排序/main.c](../堆排序/main.c)。

数组按层存放一棵完全二叉树。下标从 0 开始，`parent` 的左孩子为 `parent * 2 + 1`，右孩子为 `parent * 2 + 2`。非根节点 `child` 的父节点为 `(child - 1) / 2`。

建大堆时，`AdjustDown` 先选较大的孩子。孩子值大于父节点时交换，再沿着这条路径向下调整。子树可以先从叶子往根处理，数组中最后一个非叶节点是 `n / 2 - 1`，所以建堆循环必须用 **`i--`**。

```c
int i=n/2-1;
for(;i>=0;i--){
     AdjustDown(a, n, i);
}
for(int end=n-1;end>0;end--){
    int tmp=a[0];
    a[0]=a[end];
    a[end]=tmp;
    AdjustDown(a, end, 0);
}
```

建好大堆后，`a[0]` 是当前最大值。交换后 `a[end]` 已归位，传给 `AdjustDown` 的 `end` 是剩余堆的**长度**，堆的有效下标到 `end - 1`。建堆花 O(n)，随后最多做 n − 1 次向下调整，总时间为 O(n log n)。

## 5. 冒泡排序 BubbleSort

源码见 [冒泡排序/main.c](../冒泡排序/main.c)。

外层 `i` 记录已做了几轮，内层比较 `a[j]` 与 `a[j + 1]`。左边大才交换，每轮把剩余区间的最大值送到右端。因此内层边界是 `j < n - 1 - i`。

仓库里把交换标记命名为 `flag`，也常写作 `exchange`。每轮将它清零，发生交换时置为 1。一整轮都没有交换，就用下面的判断提前退出。已经有序时只做一轮。两个相等元素不会互换。

```c
if (flag == 0)
    break;
```

## 6. 快速排序 QuickSort

两个文件各有自己的 `PartSort` 和 `main`，分别编译运行。它们都对闭区间 `[left, right]` 排序，划分后用返回的基准位置跳过基准，递归处理其左右两段。

### Lomuto 前后指针法

源码见 [快排/lomuto.c](../快排/lomuto.c)。

`keyi = right` 把基准留在右端，`cur` 从左向右扫描，`prev` 从 `left - 1` 开始，记录严格小于基准的区域 `[left, prev]` 的右边界。遇到较小元素，先扩展这个区域，再把元素交换进去。

```c
while(cur<keyi){
    if(a[cur]<a[keyi]){
        prev++;
        int tmp=a[cur];
        a[cur]=a[prev];
        a[prev]=tmp;

    }
    cur++;
}
```

扫描结束后，源码把 `prev` 再加 1，再交换 `a[keyi]` 和 `a[prev]`。这个位置左边全小于基准，右边大于或等于基准。

### Hoare 左右指针法

源码见 [快排/hoare.c](../快排/hoare.c)。

此实现用左端的 `a[left]` 作基准 `key`，`i` 在左、`j` 在右。因为要在最后将左端基准换到相遇位置，所以先移动右侧的 `j`。右边找小于 `key` 的元素，左边找大于 `key` 的元素，找到后且 `i < j` 才交换。相遇后将 `a[left]` 和 `a[i]` 交换，返回 `i`。

```c
while(j>i&&a[j]>=key){
    j--;
}
while(j>i&&a[i]<=key){
    i++;
}
```

两个独立版本都以 `left >= right` 结束递归。例如返回位置是 `p`，接下来处理 `[left, p - 1]` 和 `[p + 1, right]`。固定选端点时，已排序或全相等的数组容易让每轮只归位一个基准，最坏耗时 O(n²)，递归栈也可能增长到 O(n)。

## 7. 归并排序 MergeSort

源码见 [归并排序/main.c](../归并排序/main.c)。

归并排序采用分治。对闭区间 `[left, right]`，用下面三次调用的顺序，先排左半边 `[left, mid]`，再排右半边 `[mid + 1, right]`，最后把两段有序区间合并。长度为 0 或 1 时满足 `left >= right`，直接返回。

```c
int mid = left + (right - left) / 2;
MergeSortInternal(a, tmp, left, mid);
MergeSortInternal(a, tmp, mid + 1, right);
Merge(a, tmp, left, mid, right);
```

用 `[0, 3]` 跟一遍。它先调用 `[0, 1]`，后者又调用 `[0, 0]`。`[0, 0]` 的 `return` 只结束这一次调用，回到 `[0, 1]` 后继续调 `[1, 1]`，然后合并成有序的 `[0, 1]`。回到 `[0, 3]` 时才轮到右半边 `[2, 3]`，最后合并整段。

`Merge` 的三个下标分别是 `i = left`（左段读到哪）、`j = mid + 1`（右段读到哪）、`k = left`（临时数组写到哪）。每次取较小的值，两边相等时用 `<=` 先取左边，这样较早出现的元素会排在前面。一侧读完后复制另一侧的尾部，再把 `tmp[left..right]` 写回原数组。

```c
if(a[i]<=a[j]){
    tmp[k++]=a[i++];
}else{
     tmp[k++]=a[j++];
}
```

最外层用 `malloc` 申请一个长度为 `n` 的 `tmp`，供所有递归调用复用。申请失败时直接返回，正常排序完成后由最外层调用 `free(tmp)`。辅助数组和递归栈合计 O(n)。

## 8. 计数排序 CountSort

源码见 [计数排序/main.c](../计数排序/main.c)。

这个版本只支持**非负整数**。它先扫描数组查找 `max`，发现负数就退出。因为下标对应数字本身，计数数组需要 `max + 1` 格才能从 0 数到 `max`。代码检查分配大小，用 `size_t` 计算长度，再用 `calloc` 申请并清零。

```c
for (int i = 0; i < n; i++)
    count[a[i]]++;

int index = 0;
for (size_t value = 0; value < range; value++)
{
    while (count[value] > 0)
    {
        a[index++] = (int)value;
        count[value]--;
    }
}
free(count);
```

例如 `[3, 0, 3, 2]` 会记下一个 `0`、一个 `2`、两个 `3`，再按下标从小到大写回。申请失败时原数组保持原样。即使只有几个元素，最大值很大时仍要为整个值域申请空间。该实现重写的是裸整数值，没有保留等键记录原始顺序的机制。

## 复杂度和稳定性对照

稳定性指排序后，相同键的元素仍按原来的顺序出现。表里的 `k` 是计数数组的长度 `max + 1`。

| 算法 | 时间复杂度 | 额外空间 | 稳定性 |
| --- | --- | --- | --- |
| 插入 | 最好 O(n)，平均、最坏 O(n²) | O(1) | 稳定 |
| 希尔 | 取决于增量序列，本例折半增量最坏 O(n²) | O(1) | 不稳定 |
| 选择 | O(n²) | O(1) | 不稳定 |
| 堆 | O(n log n) 上界 | O(1) | 不稳定 |
| 冒泡 | 最好 O(n)，平均、最坏 O(n²) | O(1) | 稳定 |
| 快速（两种独立版） | 平均 O(n log n)，最坏 O(n²) | 平均 O(log n)，最坏 O(n) | 不稳定 |
| 归并 | O(n log n) | O(n) | 稳定 |
| 计数（频数回填） | O(n + k) | O(k) | 仅回填整数值，不保证等键记录顺序 |

仓库中的 [Sort.c](Sort.c) 还提供了可复用的插入、希尔、选择、堆和快速排序函数。共享版快排递归处理较短的一侧，再用循环处理另一侧，最坏递归栈为 O(log n)。

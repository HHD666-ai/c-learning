# LeetCode 88：合并两个有序数组

## 题目目标

给定两个非递减数组 `nums1` 和 `nums2`。`nums1` 的总长度为 `m + n`，其中前 `m` 个元素是有效数据，后 `n` 个位置是为合并预留的空间。

要求把 `nums2` 合并到 `nums1` 中，并让最终的 `nums1` 仍然保持非递减顺序。

## 核心思路

从后往前合并，使用三个下标：

- `end1 = m - 1`：指向 `nums1` 最后一个还没处理的有效元素；
- `end2 = n - 1`：指向 `nums2` 最后一个还没处理的元素；
- `end = m + n - 1`：指向 `nums1` 当前最后一个需要填写的位置。

当 `nums1[end1]` 和 `nums2[end2]` 都存在时，比较两个数的大小，谁更大就把谁放到 `nums1[end]`，然后对应下标和 `end` 向前移动。

主循环结束后，如果 `nums2` 还有剩余元素，就继续复制到 `nums1` 前面；如果是 `nums1` 有剩余，则不用继续复制，因为这些元素本来就在正确位置。

## 为什么从后往前

如果从前往后写入 `nums1`，可能覆盖掉 `nums1` 中还没有比较的原始有效数据。

从后往前则可以直接利用 `nums1` 后面的预留空间，不需要额外数组。

## 学习过程中重点理解

以：

```text
nums1 = [4,5,6,0,0,0]
m = 3
nums2 = [1,2,3]
n = 3
```

为例：

```text
[4,5,6,0,0,0]
→ [4,5,6,0,0,6]
→ [4,5,6,0,5,6]
→ [4,5,6,4,5,6]
→ [4,5,3,4,5,6]
→ [4,2,3,4,5,6]
→ [1,2,3,4,5,6]
```

这里 `nums1` 虽然总共有 6 个位置，但原本只有前 3 个元素是有效数据，后面的 `0,0,0` 是预留空间。

## 复杂度

- 时间复杂度：`O(m + n)`
- 空间复杂度：`O(1)`
